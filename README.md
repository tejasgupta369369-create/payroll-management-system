# Central Government Based Payroll System

A desktop-based Payroll Management System developed in Python using Tkinter and SQLite. The application automates employee record management, salary computation, and payslip generation based on Central Government payroll concepts.

## Features

* Employee Management (Add, View, Delete Employees)
* SQLite Database Integration
* Salary Calculation
* Dearness Allowance (DA)
* House Rent Allowance (HRA)
* Transport Allowance (TA)
* National Pension System (NPS) Deduction
* Gross and Net Salary Computation
* Automated Payslip Generation
* User Authentication (Admin Login)
* Graphical User Interface (Tkinter)

## Technologies Used

* Python
* Tkinter
* SQLite3

## How to Run

```bash
python3 main.py
```

## Project Structure

* database.py – Database operations
* employee.py – Employee model
* payroll.py – Salary calculations and payslip generation
* login.py – Authentication system
* main.py – Main GUI application

This project was developed for learning payroll management systems, database integration, GUI development, and Python application architecture.
